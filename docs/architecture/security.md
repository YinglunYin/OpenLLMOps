# 安全边界

## 身份与入口

- 管理界面为内网单管理员模式，仍必须使用 HTTPS、强密码和短期会话。
- OpenAI 兼容接口使用可轮换 API Key。数据库只保存带独立盐值的哈希与可识别前缀，明文只在创建时显示一次。
- 登录、密钥创建/吊销、模型导入、部署变更、训练终止和数据删除必须写审计日志。

## Node Agent

- API 不直接拥有 Docker Socket；只有 Node Agent 可操作动态容器。
- Agent 请求带时间戳、随机数和 HMAC，拒绝超时及重放请求。
- 镜像、命令入口、挂载根目录、端口范围、GPU ID 与资源上限均使用白名单校验。
- 不接收任意 shell 字符串。高级 vLLM 参数必须解析为结构化参数并逐项校验。
- 动态容器默认只读根文件系统、最小 Linux capabilities、无特权模式，并使用独立网络。

## 模型与数据

- 全局关闭 `trust_remote_code`，拒绝 pickle 权重，首版只接受 Safetensors。
- 解压和复制时规范化路径，拒绝绝对路径、`..`、设备文件和越界软链接。
- 数据集上传限制文件大小、行长和 JSON 深度；预览内容按文本展示并转义，禁止当作 HTML 渲染。
- 模型令牌、ModelScope 凭证等密钥不得写入任务日志或容器参数列表，使用只读 secret 文件传入。

## 删除与保留

界面删除默认是可恢复的软删除。物理清理必须由独立垃圾回收任务执行，并在执行前再次检查引用、保留期和解析后的绝对路径。任何递归删除都不得以环境变量未展开的路径为目标。
